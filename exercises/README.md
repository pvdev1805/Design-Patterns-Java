# Exercises

Exercises are organised by phase and day. Attempt the problem before consulting the reference solution.

- `problem.md`: scenario, requirements and acceptance criteria.
- `starter/`: intentionally incomplete or naive code, outside the Maven build.
- `solution.md`: explanation and links to canonical, tested Java reference implementations.

Reference implementations belong under `src/main/java/` and tests under `src/test/java/`. The existing Day 01 standalone solution is transitional and will be migrated during Day 01 completion.

Start with [Day 01 — Product Encapsulation](phase-01/day-01/problem.md).
